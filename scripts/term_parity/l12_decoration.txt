# l12: Underline, underline colour (SGR 58), strikethrough, inverse and dim decorations on blank cells.
# Run: python3 scripts/term_parity/compare.py scripts/term_parity/l12_decoration.txt
# Setup as in l01_sgr.txt. All five decorated segments sit on one printed row, so the row stays in
# RRiter's short panel. Segment k covers cells 5k..5k+3 (its first cell is 5k); the cell separator
# is a plain space. The row is found by the word `decorow`, built as deco''row in the command.
# Line geometry (thickness, centre offset from baseline / char_h) is compared per segment; the
# colours are compared by `dump row` (fg, bg, underline_color; inverse cells skip fg/bg as palette).
# Each line reports its top and bottom edge against the baseline (px); labels with `underline` also
# check the spec L12 rule that the underline top is not above `layout.baseline`.
# Underline colour falls back to fg when SGR 58 is absent (spec L12).
