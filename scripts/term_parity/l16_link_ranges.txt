# l16: hovered link whose cells span two rows and two segments of one row.
# Run: python3 scripts/term_parity/compare.py scripts/term_parity/l16_link_ranges.txt
# Both segments of row 1 and the segment of row 2 carry the same `id=a` and URI, so they are one
# link (spec parity 5.x OSC 8: cells connect when URI and non-empty id match). The output uses
# absolute CUP positions (`ESC[2;1H` is the grid row with index 1), so the ranges' row numbers do not
# depend on how many rows each panel shows. `; read x` keeps zsh from redrawing its prompt over the
# output (a 3-row grid scrolls on the prompt redraw); `key enter` ends each wait. Row 0 is cleared
# first, so the typed command echo (its wrap and prompt differ by app) is not in the compared text.
# Expected by hand from the OSC 8 cells and `hovered_link.ranges` format ([row, col_start, col_end),
# Ronsole spec 2026-10-23 section 5 line 184): pointer on (0,1) and (1,2) gives
# [[1,0,2],[1,3,5],[2,0,2]]; the space at column 2 is outside the link.
# The `#@click_ui` markers enter IDE mode and open the terminal panel on RRiter, as in l01_sgr.txt.
