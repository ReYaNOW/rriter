# l10: bracketed paste (mode 2004) through the terminal's Ctrl+V path. The clipboard is set with OSC 52
# (no selection: the drag-select + ctrl+c path is not in this file). Reader: function `r` from
# l08_kitty_keys.txt, same §9.1 hex protocol.
# Expected (spec 9.2 L10, parity spec 5.x `terminal_bracketed_paste_bytes`): with 2004 set, pasting "hi"
# sends ESC[200~ hi ESC[201~ = 1b5b3230307e 6869 1b5b3230317e.
# The reader sets mode 2004 itself: zsh's line editor clears it when a command starts, so a mode set
# in an earlier prompt is off while the reader runs.
# Mouse reports (modes 1000 + SGR 1006) follow the paste, read by the same reader. 1004 focus
# reporting is not in this file (Q26: Ronsole-only test).
# `type` turns `\n` into a newline, so the printf calls use `\012` for LF.
# Run: python3 scripts/term_parity/compare.py scripts/term_parity/l10_paste_mouse.txt
