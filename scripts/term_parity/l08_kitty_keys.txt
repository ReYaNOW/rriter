# l08: keyboard bytes the terminal sends to the application (Kitty flags, Shift+Enter, Ctrl+C, IME).
# Reader: function `r` (§9.1 of the Ronsole headless spec): raw mode, READY marker with \r\n, then the
# hex of the bytes sent by the terminal until 1 s of silence, then the end marker and `stty sane`.
# Expected bytes (protocol ref "Worked byte examples" and parity spec 5.3, decision 13):
#   flags 0: Ctrl+C -> 03; Shift+Enter -> 1b0d (ESC CR, decision 13)
#   flags 1: Shift+Enter -> CSI 13;2u = 1b5b31333b3275; Ctrl+C -> CSI 99;5u = 1b5b39393b3575;
#            Escape press -> CSI 27u = 1b5b323775
#   flags 3 (1+2): Escape press CSI 27u = 1b5b323775, Escape release CSI 27;1:3u = 1b5b32373b313a3375
#   IME text "привет" -> UTF-8 text path at any flags: d0bfd180d0b8d0b2d0b5d182
# `key --char` (Ctrl by physical key with a Cyrillic layout) is in l08b_kitty_flag8_repeat_char.txt.
# Run: python3 scripts/term_parity/compare.py scripts/term_parity/l08_kitty_keys.txt
