# Темы редактора и интерфейса — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 5 переключаемых тем (Dracula, One Dark, Forest, Sepia, One Light) для редактора/подсветки и интерфейса, связанных по умолчанию, с раздельным режимом.

**Architecture:** Модуль `src/theme.rs` строит палитры по `ThemeId`. Спаны подсветки хранят `SyntaxRole` (u8), цвет берётся при отрисовке из палитры поверхности. `Renderer` держит редакторский `Theme` и `UiPalette`; единственная точка смены — `App::apply_themes`. Этап 2 переносит ~1000 UI-литералов в роли `UiPalette` с побитным сохранением Dracula.

**Tech Stack:** Rust, собственный OpenGL-рендер, headless-драйвер `scripts/rriter_headless.py`, тесты `make test TEST_FILTER=…`.

**Spec:** `docs/superpowers/specs/2026-10-04-themes-design.md` — исполнитель читает её целиком: палитры (hex), роли, факты с `file:line`.
