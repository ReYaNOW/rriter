## Review Focus

1. Индексы строк и `scroll_y` после resize (reflow крейта): выделение сбрасывается, прилипание к низу сохраняется, headless-тесты с номерами строк (`ui_tests_terminal.rs:151-182`) — ожидания меняются только здесь (спека 7, 8) — Task 2.
2. Фон по умолчанию не рисуется при inverse/truecolor: клетка `ESC[7m` с фоном по умолчанию рисует фон (fg по умолчанию), обычная — нет — Task 2.
3. Windows AltGr (Ctrl+Alt с текстом) — текст, не `CSI u`; Ctrl+C без выделения — `0x03` через кодировщик; IME-коммит — путь текста при любых флагах — Task 4.
4. Мышь при tracking: реальные колонка и строка видимой области (не 1;1), обхода tracking модификатором нет (как в Ronsole), колесо без tracking в альт-экране — стрелки, как сейчас — Task 5.
5. `printf '\e[?2026h'` без `l` в фоновой вкладке при простое окна: через 150 мс вывод виден, цикл не крутится вхолостую (`WaitUntil`, не `Poll`), прочие сроки цикла (`deadline_wake_at`, `Poll`) не затёрты, после возврата из `render_suspended` срок не потерян — Task 6.
6. Ссылка `file://` не запускает ничего ни на одной платформе: запускаемое → показать в файловом менеджере (macOS — всегда `open -R`, в том числе бандл-каталог), опенер получает канонический путь (без `\\?\` на Windows), базовый список Windows не зависит от `PATHEXT` — Task 6.
7. Фокус 1004: при переключении и закрытии вкладки старая получает `ESC[O`, новая `ESC[I`; Kitty Release при терминале-владельце доходит до кодировщика из `key_routes.rs` — Task 4, 5.

Для задач с внешним форматом (2, 4, 5, 6): ожидания тестов совпадают со справочником и таблицами спеки 5.1–5.8; байты кодировщиков — те же, что тесты крейта (их не дублировать, проверять маршрут хоста).
